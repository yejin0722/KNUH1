# **공공기관 리뉴얼** 👨‍⚕️강원대학교 병원

## 🛠 작업자 : 조예진

## 📌 프로젝트 소개

### 메인 페이지 
본 프로젝트는 **강원대학교병원** 공식 홈페이지의 UI/UX를 개선하고, **사용성과 접근성을 고려해 전면 리디자인**한 웹사이트입니다.<br>
**기존 사이트는 구형 브라우저(IE11)** 에 최적화되어 있어 **보안 취약점에 노출될 위험, 디자인 노후화, 낮은 가독성, 모바일 대응 미흡** 등의 문제를 안고 있었습니다.<br>
이에 따라 **현대적인 인터페이스, 명확한 정보 구조, 반응형 구현** 을 목표로 리디자인을 진행하였습니다.

- **목표**: 정보 접근성 개선, UI 신뢰도 향상, 모바일 환경 대응
- **타겟**: 진료 예약 및 증명서 발급이 필요한 일반 국민
- **형태**: 정적 웹사이트 (GitHub Pages 배포)
